# HeartTrack - 血壓脈搏記錄 App

一個使用 Python 和 tkinter 開發的桌面應用程式，用於記錄和管理血壓與脈搏數據。

## 功能特色

- ✅ **數據記錄**：手動輸入收縮壓、舒張壓、脈搏等數據
- ✅ **自動分級**：根據 WHO 標準自動分類血壓等級
- ✅ **歷史查看**：查看所有歷史記錄，支援編輯和刪除
- ✅ **統計圖表**：提供週、月、年視圖的趨勢圖表
- ✅ **數據導出**：支援導出為 PDF 或 CSV 格式
- ✅ **本週趨勢**：主畫面顯示本週血壓與脈搏趨勢圖

## 安裝與執行

### 1. 確保已安裝 Python 3.8+

### 2. 使用 uv 建立虛擬環境（已建立）

```bash
uv venv
```

### 3. 啟用虛擬環境

**Windows (PowerShell):**
```powershell
.venv\Scripts\activate
```

**Windows (CMD):**
```cmd
.venv\Scripts\activate.bat
```

**Linux/Mac:**
```bash
source .venv/bin/activate
```

### 4. 安裝依賴套件（已安裝）

```bash
uv pip install -r requirements.txt
```

### 5. 執行應用程式

```bash
python main.py
```

## 使用說明

### 新增記錄

1. 點擊主畫面的「➕ 新增記錄」按鈕
2. 填入收縮壓、舒張壓、脈搏數值
3. 選擇測量側（左手/右手）
4. 可選擇使用當前時間或手動設定時間
5. 可選填備註（如：剛運動完、服藥後等）
6. 點擊「儲存」按鈕

### 查看歷史記錄

1. 點擊「📋 歷史記錄」按鈕
2. 在表格中查看所有記錄
3. 可選擇記錄進行編輯或刪除

### 查看統計圖表

1. 點擊「📊 統計圖表」按鈕
2. 選擇時間範圍（週/月/年）
3. 查看血壓與脈搏的趨勢圖

### 導出資料

1. 點擊「💾 導出資料」按鈕
2. 選擇導出格式（PDF 或 CSV）
3. 選擇儲存位置
4. 完成導出

## 血壓分級標準

根據 WHO 標準：

- **正常**：收縮壓 < 120 且 舒張壓 < 80
- **正常偏高**：收縮壓 120-129 且 舒張壓 < 85
- **一級高血壓（輕度）**：收縮壓 130-139 或 舒張壓 85-89
- **二級高血壓（中度）**：收縮壓 140-159 或 舒張壓 90-99
- **三級高血壓（重度）**：收縮壓 160-179 或 舒張壓 100-109
- **高血壓危象**：收縮壓 ≥ 180 或 舒張壓 ≥ 110
